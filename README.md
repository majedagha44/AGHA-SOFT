# AGHA-SOFT
مشروع آغا سوفت (AGHA SOFT): نظام ERP ومحاسبي متكامل وقابل للتطوير، مخصص لإدارة الشركات والأنشطة التجارية، مع تطبيق عملي على شركة تجارة مواد غذائية. يهدف المشروع إلى بناء نظام محاسبي احترافي يشمل الحسابات والعملاء والموردين والمخزون والمبيعات والمشتريات والبنوك والتقارير المالية، مع اختبارات محاسبية وبرمجية وتوثيق مراحل التطوير.
